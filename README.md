# BNSC コンテンツライブラリ

BNSC（Brain & Neuro Solution Center）の会員向け動画・研究解説を探す、スマートフォン対応の検索アプリです。

## Vimeo自動同期（初期設定前・未公開）

Vimeoの **BNSC** タグを公開承認として、所有アカウントの動画メタデータだけを毎時同期する処理を追加しました。GitHub Secrets設定後に接続テストし、公開有効化後にGitHub Pagesへ自動配信します。トークンと限定公開URLは配信しません。会員認証が決まるまでVimeo動画の直接視聴は無効です。

**リポジトリ作成からAPI設定、接続テスト、公開までの手順は [VIMEO_SETUP.md](VIMEO_SETUP.md) を参照してください。** 公開フラグは初期状態で無効です。実Vimeo接続・デプロイはまだ行っていません。Vimeo以外のデータは以下のCSV管理を維持します。

## できること

- タイトル、概要、タグ、関連キーワードを横断した日本語キーワード検索
- 「動画」「研究解説」の形式で絞り込み
- トレーニング／リハビリ／療育・発達支援／脳機能・神経科学で分類
- テーマ（前庭、ASD、姿勢制御など）による絞り込み
- 「あとで見る」をブラウザ内に保存（端末間同期なし）
- 投稿日の新旧順・タイトル順に並び替え
- 該当するCAMPFIRE会員限定投稿への移動

## すぐに見た目と操作を試す

`demo_preview.html` をダブルクリックしてください。ブラウザだけで検索・フィルター・保存を試せます。これは架空データ10件のスタンドアロン版です。本番公開には使用しないでください。

## 起動手順（Mac / Codex）

1. このフォルダーを開く
2. ターミナルで `python3 -m http.server 8000` を実行
3. ブラウザで `http://localhost:8000` を開く

外部ライブラリ・APIキー・npm installは不要です。`index.html` を直接ファイルとして開くと、ブラウザによってはJSONを読み込めません。HTTPサーバー経由で開いてください。

## Vimeo以外の動画・記事をCSVで登録する方法

1. `contents.csv` をExcelやGoogleスプレッドシートで開く。
2. 所有者の投稿アーカイブから、実際の動画・記事を1行につき1件入力する。最初は `status` を `draft` にする。
3. CSV（UTF-8）で保存する。
4. 実際の題名・CAMPFIREの該当投稿URL・公開してよい短い紹介文を確認し、確認済みの行だけ `status` を `published` にする。このフォルダーで `python3 scripts/import_csv.py` を実行する。
5. `published` の行だけが `data/contents.json` に反映される。`draft` と `demo` は出力しない。前回の正常なVimeo同期データは保持する。ブラウザをリロードする。確認済み0件でも正常に変換できる。
6. 下記の公開前チェック後、`python3 scripts/build_release.py` で公開用の `dist/` を作成する。静的ホスティングには `dist/` の中身だけ配置する。フォルダー全体やCSV、デモHTMLは公開しない。通常のCSV公開は確認済み0件で停止する。Vimeoの正常同期後は `--synced` を付け、最後のタグ削除による0件も公開へ反映できる。

**CSVの列と入力例**

| 列名 | 意味 | 入力例 |
| --- | --- | --- |
| id | 一意のID（半角英数記号） | `video-001` |
| title | 実際の動画名・記事名 | `前庭機能について` |
| type | `動画` または `研究解説` | `動画` |
| category | 4つの専門領域のいずれか | `脳機能・神経科学` |
| summary | オリジナルの1〜2行紹介 | `前庭機能の評価の基本を整理` |
| tags | テーマを `|` で区切る | `前庭|眼球運動|姿勢` |
| keywords | 別名、表記ゆれを `|` で区切る | `VOR|Vestibular` |
| duration_minutes | 動画時間。記事は0 | `60` |
| published_at | 公開日（不明なら空白） | `2026-10-25` |
| url | **CAMPFIRE投稿のURL**。未登録なら空白 | `https://community.camp-fire.jp/...` |
| status | `draft`（下書き）／`published`（確認済み実コンテンツ）／`demo`（架空） | `draft` |

CSV全列の順序を保持してください（`status` は末尾）。旧10列CSVも読み込めますが、status列なし・空欄は安全のため `draft` として非掲載になります。URLが入っているだけでは公開されません。

CSV全列を保持してください。タイトル・説明・カテゴリ・タグなどの検索用メタデータのみを保存し、動画本体・会員限定投稿の本文・アクセス用パスワードを入力しないでください。

### URLについて

会員限定動画への直接リンク（Vimeo、YouTubeなど）は**登録しない方針**です。CAMPFIREの**該当する会員限定投稿ページ**のURLを登録してください。会員はCAMPFIRE側にログインして視聴します。

## 公開先

このアプリは静的HTML/CSS/JavaScriptなので、GitHub Pages、Cloudflare Pagesなど静的サイトを公開できるサービスで動作します。ホスティング環境の利用規約・現在のプラン条件は別途確認してください。

サイトを公開すると、`data/contents.json` に保存された**タイトル・概要・タグ・投稿URL等は第三者から読み取れる**状態になります。公開してよいメタデータだけ登録してください。CAMPFIRE会員資格はアプリ内で検証していません。個別会員の認証・有効期限の管理が必要になった場合は、サーバー側の認証と会員情報同期を追加する必要があります。**共通パスワードだけでは確実な会員制限になりません。**

## データの取得について

本アプリはCAMPFIREから投稿を自動取得・スクレイピングしません。現状の104件のアクティビティも自動投入されていません。CAMPFIREの動画・研究解説は管理者が自分の投稿の題名・投稿URL・紹介文をCSVへ登録します。VimeoのBNSCタグ付き動画は公式API同期で別途合流します。

## 著作権・安全性

- 元論文の本文や長文翻訳を検索インデックスに保存しない。
- 動画の複製・転載はしない。
- 研究解説は独自文章のタイトルと短い概要のみ登録する。
- 投稿閲覧資格はCAMPFIRE側で管理する。
- アプリはGoogle Analytics等の外部トラッキングを使わない。
- ブックマークはブラウザのlocalStorage内に留まり、端末間同期しない。

## 開発・保守

- `index.html`: 画面の構成
- `styles.css`: デザイン・レスポンシブ対応
- `app.js`: 検索、フィルター、保存、並べ替え
- `contents.csv`: 管理用入力データ
- `scripts/import_csv.py`: CSV検証とJSON変換
- `data/contents.json`: アプリが読む検索データ
- `AGENTS.md`: Codexなどのコーディングエージェントへの保守指示

### 公開前チェック

1. 各 `published` 行の題名と投稿URLを所有者のアーカイブ・CAMPFIRE画面で照合する。コミュニティのトップURLではなく該当投稿を指定する。URLの形式検証は投稿の実在・閲覧権限を保証しない。クエリ文字列・フラグメント付きURLは受け付けない。
2. タイトル・概要・タグが一般公開可能か確認する。下書きCSVにも個人情報・秘密情報・本文は入力しない。
3. テスト、CSV変換、HTTPサーバー経由での日本語検索・カテゴリー・保存・モバイル表示を確認する。データ0件の間は操作デモで検索等を確認する。
4. `python3 scripts/build_release.py` を実行し、`dist/` の内容を確認する。既存の `dist/` は上書きしないため、再生成前に退避する。CSVを変更したら公開用ファイルも再生成する。
5. `dist/` 内だけを配置する。現時点では実コンテンツ未提供のため未公開。
